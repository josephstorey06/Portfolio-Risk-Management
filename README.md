**Portfolio Risk Management Model**
Used Excel to create a portfolio risk management model designed to analyse a portfolio's performance, market risk and potential loses using past market data. 

**Overview**
This Excel model uses a hypothetical £1,000,000 invested 5 years ago into an equally weighted portfolio containing 5 companies, each across a different sector: Alphabet (GOOGL), Microsoft (MSFT), Exxon Mobil (XOM), JPMorgan Chase (JPM) and UnitedHealth Group (UNH). The model uses historical market data to calculate portfolio returns, volatility, correlations, drawdowns and a range of other portfolio risk measures.

**Risk Analysis**
The model calculates one-day 95% and 99% Value-at-Risk (VaR) using historical and parametric approaches. It also uses these to calculate the expected shortfall.

**Stress Testing**
The model includes several hypothetical scenarios and how they would affect the market; The dashboard then allows a scenario to be selected and displays the corresponding portfolio impact.

**Dashboard**
The dashboard provides an overview of: Portfolio Value, volatility, VaR, stress-test results and expected shortfall. It does this through a mixture of figures and charts.

**Assumptions**
Assumed that the initial portfolio value was £1,000,000 with an equal asset allocation of 20% to all companies. I also averaged the trading days, so assumed there were only 252 trading days per year. Historical market data was also used with the transaction costs and taxes excluded.

**Limitations**
Historical returns may not represent future performance. In the returns, transaction costs and taxes are not included. As well as this, the stress-test results are based on the assumptions that were made. The portfolio only contains five companies.
